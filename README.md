# MobileLabsRN2026# 

Репозиторій містить виконані лабораторні роботи з дисципліни розробки мобільних застосунків на React Native.

У межах лабораторних робіт було реалізовано:
- створення мобільних застосунків за допомогою Expo;
- роботу з базовими компонентами React Native;
- реалізацію навігації між екранами;
- використання Drawer Navigator, Stack Navigator та вкладеної навігації;
- роботу з FlatList та SectionList;
- оптимізацію відображення великих списків;
- реалізацію жестових взаємодій користувача;
- стилізацію інтерфейсу та підтримку світлої/темної теми.

## Структура репозиторію

- `lab1` — базовий React Native застосунок з навігацією та компонентами;
- `lab2` — вкладена навігація, FlatList та SectionList;
- `lab3` — гра-клікер з кастомними жестами та стилізацією.

## Використані технології

- React Native
- Expo
- React Navigation
- React Native Gesture Handler
- Styled Components
